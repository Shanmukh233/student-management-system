# Student Management System

A simple command-line Student Management System developed using Python.

## Features

- Add students
- View all students
- Search students by ID
- Update student information
- Delete students
- Calculate average marks
- Automatically calculate grades
- Display the top-performing student
- Store student information in JSON
- Input validation

## Technologies Used

- Python
- JSON
- File Handling
- Object-free procedural programming
- Exception Handling
